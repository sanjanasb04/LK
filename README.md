# LearnersKart Project

This repository contains the complete LearnersKart web platform:

## ?? Repository Structure
- **learnerskart-site/** — Main website frontend built with React, Tailwind CSS, and Vite.
- **learnerskart-lms/** — LMS system with React client and Express / Node.js backend.

## ?? Running the Project

### 1. Main Website
\\\ash
cd learnerskart-site
npm install
npm run dev
\\\
Runs on http://localhost:5173

### 2. LMS (Backend + Frontend)
\\\ash
cd learnerskart-lms
npm install
npm run dev
\\\
Runs on http://localhost:5174 (client) & http://localhost:5001 (API)
